// features
01

raw sockets

BSD sockets API. socket(), bind(), listen(), accept(). No frameworks.

02

http/1.1 parsing

Parses raw request line, headers, method, path, version from buffer.

03

routing system

Function pointer routing table. Register any handler for any route.

04

body parsing

Reads Content-Length, extracts body after CRLF. Handles POST, PATCH.

05

static files

Serves HTML, CSS, JS, images with correct MIME types from disk.

06

request logging

Timestamped access log. Method, path, status code, response time.
